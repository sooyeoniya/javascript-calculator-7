# javascript-calculator-precourse

## ✅ 기능 목록

### 입력

  - [x] `덧셈할 문자열을 입력해 주세요.` 프롬프트 메시지 출력
  - [x] 구분자와 양수로 구성된 문자열 입력 받아 저장

### 기능

  - [x] 커스텀 구분자 추출
  - [x] 문자열에서 숫자 부분만 분리
  - [x] 구분자에 의해 추출된 전체 숫자 덧셈

### 출력

  - [x] 출력 형식에 맞게 덧셈 결과 출력

### 예외 처리

  - [x] ` ` 아무것도 입력되지 않은 경우 0 출력
  - [x] `//?\n` 커스텀 구분자만 있고 아무것도 입력되지 않은 경우 0 출력
  - [x] `,1,2,3,` 앞뒤로 구분자 존재하는 경우 허용
  - [x] `//1\n21315` 커스텀 구분자가 숫자인 경우 허용
  - [x] `//?!@\n1?2!3@4` 커스텀 구분자가 여러 개 정의된 경우 허용
  - [x] ` //?\n 1 ? 2 , 3 ` 숫자 앞뒤로 공백이 있는 경우 공백 제거
  - [x] `// \n1 2 3 4` 커스텀 구분자 공백인 경우 허용
  - [x] `1,,2,:3` `//-\n1,-3,4` 구분자가 연속으로 나오는 경우 허용
  - [x] `//:\n1:2:3` 커스텀 구분자가 기본 구분자와 동일한 경우 Set에 의해 중복 제거
  - [x] `//??\n1??2?3?4?5` 커스텀 구분자가 중복된 값이 있을 경우 Set에 의해 중복 제거
  - [x] `//?\n//!\n//@\n1?2!3@4n5\6/7,8:9` 커스텀 구분자 정의가 여러 개 존재하는 경우 마지막 줄바꿈 문자로 인식
  - [x] `///\n` `////\n` `//\\n1\2\3` `//\n\n` `//\\n\n` `//?\n\n` 커스텀 구분자에 특수문자가 들어가는 경우
  - [x] `//\n1,2:3` 커스텀 구분자에 아무것도 존재하지 않는 경우 에러
  - [x] `1//?\n3,4,5` `1:3,4,5//?\n` `//?2,3,4` `12\n3,4,5` 문자열 형식이 맞지 않는 경우 에러
  - [x] `-1,2,3` `1,-2,3` 음수가 존재하는 경우 에러
  - [x] `//!\n1,2?5` `1,2!3:4` `//?\n1?2,3 4 5` 정의하지 않은 구분자가 있는 경우 에러
