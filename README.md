# javascript-calculator-precourse

## ✅ 기능 목록

### 입력

  - [ ] `덧셈할 문자열을 입력해 주세요.` 프롬프트 메시지 출력
  - [ ] 구분자와 양수로 구성된 문자열 입력 받아 저장

### 기능

  - [ ] 커스텀 구분자 추출
  - [ ] 문자열에서 구분자와 숫자 분리
  - [ ] 구분자에 의해 추출된 전체 숫자 덧셈

### 출력

  - [ ] 출력 형식에 맞게 덧셈 결과 출력

### 예외 처리

  - [ ] ` ` 아무것도 입력되지 않은 경우 0 출력
  - [ ] `//?\n` 커스텀 구분자만 있고 아무것도 입력되지 않은 경우 0 출력
  - [ ] `//\n1,2:3` 커스텀 구분자에 아무것도 존재하지 않는 경우 에러
  - [ ] `1//?\n3,4,5` `1:3,4,5//?\n` `//?2,3,4` `12\n3,4,5` 문자열 형식이 맞지 않는 경우 에러
  - [ ] `//!\n1,2?5` `1,2!3:4` 정의하지 않은 구분자가 있는 경우 에러
  - [ ] `,1,2,3,` 앞뒤로 구분자 존재하는 경우 허용
  - [ ] `//1\n21315` 커스텀 구분자가 숫자인 경우 허용
  - [ ] `//:\n1:2:3` 커스텀 구분자가 기본 구분자와 동일한 경우 에러
  - [ ] `//?\n//!\n//@\n` 커스텀 구분자가 여러 개 존재하는 경우 허용
  <!-- - [ ] `1,,2,:3` 구분자가 연속으로 나오는 경우 에러 -->
  <!-- - [ ] `//?!@\n1?!@2` 문자열로 된 커스텀 구분자인 경우 허용 -->
